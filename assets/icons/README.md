# UI Icons

Source: [Lucide](https://github.com/lucide-icons/lucide), downloaded 2026-09-17.

The SVG paths are from Lucide. Only `stroke="currentColor"` was changed to white so Godot can tint the textures consistently for normal, disabled and selected states. Building rendering retains the texture references in `scripts/ui_theme.gd`.

The original ISC license and the MIT notice for Feather-derived icons are preserved in [LICENSE](LICENSE).
