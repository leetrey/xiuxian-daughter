# 修仙养女儿 · 阶段三最小闭环原型

> Godot 4.7 项目。跑通 GDD §13 交付顺序里的「排日程 → 属性/境界变化 → 女儿反馈」最小闭环，验证 GDD §1 的 **H1 养成感假设**（成长被看见的频率 = 养成感强度）。

## 一、怎么跑

**方式 A · Godot 编辑器（推荐）**
1. 打开 Godot 4.7（本机已装：`/Applications/Godot.app`）
2. 「导入」→ 选择本目录 `xiuxian-daughter/` 下的 `project.godot`
3. 按 F5 运行

**方式 B · 命令行**
```bash
cd /Users/leet/WorkBuddy/xiuxian-daughter
godot          # 打开编辑器
godot --path . # 直接运行游戏
```

## 二、这个原型现在能做什么

| 能力 | 状态 |
|---|---|
| 女儿状态卡：境界 + 四大主属性（16 细分）+ 情缘 + 心魔 + 精力 + 灵石 | ✅ |
| 12 个日程活动：修炼 / 参悟 / 杂学四艺 / 历练 / 闭关 / 打工 / 谈心 / 游历 | ✅ |
| 排日程 → 属性/境界实时变化 → 女儿一句话反馈 | ✅ |
| 境界突破（练气→…→化神）：立绘 emoji/颜色随境界变化 | ✅ |
| 精力 / 灵石不足的拒绝逻辑 | ✅ |
| 心魔过高变色警示（≥60 变红） | ✅ |
| 时间推进（月 / 年龄 / 精力回满） | ✅ |

**没做的（阶段四内容）**：事件系统、血仇/隐忍双线选项、12 结局判定、真实像素立绘、战斗、经济 Sources/Sinks 完整链。

## 五、数值说明（重要）

所有数值都是 **骨架值，标 [PLACEHOLDER]**，等 playtest 校准：

| 变量 | 当前值 | 待验证 |
|---|---|---|
| 精力上限 | 10 / 月 | 「够做但不够贪」的手感 |
| 活动精力消耗 | 2~5 | 每月实际做 2~4 件事是否合适 |

| 心魔警戒线 | ≥60 变红 | 突破失败惩罚阈值 |

对应 GDD §10 的验证路径：先跑最小闭环，看玩家是否在目标时长内达成阶段目标，再回头调这几个数。
