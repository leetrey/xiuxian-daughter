# 主体交互方案

状态：交互提案，已确认边界单独标注。规则依据 [主体设计基线](01-game-design.md)；实际页面与试作差异见 [开发进度](05-development-progress.md)。本文描述目标交互，不代表全部页面已经实现或视觉定稿。

## 1. 交互目标

玩家应能回答四个问题：

1. 女儿现在擅长什么，接下来想培养什么？
2. 本回合还有哪些自由活动可以做，日程准备好了吗？
3. 洞天当前会消耗什么、产出什么，哪里没有安排？
4. 本次成长或产出打开了什么新的选择？

两条路线共享资源与反馈，但不显示一个要求二者同步完成的总进度条。洞天落后不是默认错误，不用持续警报催促玩家追赶。

## 2. 页面结构提案

| 页面 | 主要职责 | 从哪里进入 |
|---|---|---|
| 新周目准备 | 分配继承预算，确认本局起点 | 标题或结局 |
| 养成主界面 | 女儿反馈、自由活动入口、日程草稿与确认 | 完成回合开始剧情后 |
| 洞天 | 放置、移动、生产安排、御灵分配、产出预测 | 主界面 |
| 人物 | 女儿与伙伴属性、关系、三件装备、六门功法 | 主界面或战前准备 |
| 背包 | 查看库存，使用、送礼、交易所需物品 | 主界面或当前活动 |
| 剧情记录 | 当前已知任务、完成记录、材料条件 | 主界面 |
| 冒险 | 目的地、路线、战前准备、战斗与战利品 | 自由活动入口 |
| 结算 | 培养反馈、生产入库、剧情升级与下一回合 | 确认日程后自动进入 |

比赛和普通对话作为自由活动的局部流程，不各自扩成完整导航系统。人物配置与战前准备复用同一套展示，不维护两份装备状态。

## 3. 新周目准备

页面只处理本局开局选择：

- 展示已获得的继承预算、已分配点数、剩余点数。
- 分项选择属性、土地、图纸、御灵、资源与开局天赋。
- 培养槽显示本局将获得 3、4 或 5 槽；增加槽位与增加精力不是同一效果。
- 土地与图纸分别展示，不用一个含糊的“洞天等级”遮盖二者区别。
- 确认后生成新局，不修改其他存档，也不永久扣掉账号成就预算。

不在此阶段增加推荐流派生成器、随机洗点、局内天赋树等功能。各继承选项成本与互斥规则待定后再确认具体控件。

## 4. 养成主界面与培养日程

### 4.1 信息布局草案

顶部：灵石、自由活动剩余精力、当前压力。

主体：女儿当前阶段立绘与反馈；四维 A 摘要；自由活动入口。

日程区：本局数量固定的培养槽；可选基础或特殊日程；本次预计消耗；确认按钮。

导航：洞天、人物、背包、剧情记录。

这是信息层级示意，不是最终左右布局。具体季节或回合进度如何展示待确认，不显示具体年龄、年份、日期。空间不足时保留核心信息优先级，不把所有细分属性、库存和任务同时堆在首页。

当前视觉试作（2026-09-17）：家园背景和女儿立绘铺满主屏，左侧仅保留四维摘要，右上显示精力与压力；底部进入自由活动、洞天和日程。细分属性、日程、结果使用可收起浮层；关闭只收起界面，不改变阶段或执行规则。用户明确要求以游戏场景为主体，不采用常驻多栏看板；具体素材和控件装饰仍待审阅。

### 4.2 日程操作

1. 选择一个培养槽，选择已解锁活动。
2. 活动详情展示成长方向、压力变化、额外材料成本和不可选原因。
3. 在自由活动阶段可以修改、替换、调整顺序；具体排序操作以简单按钮优先，不把拖放作为必需功能。
4. 页面显示当前安排的预计成本与增长信息。培养结果有随机性，不展示为保证到账的精确增长。
5. 玩家可以进入洞天或做自由活动，返回时保留日程草稿。
6. 确认前进行必要校验与闲置建筑提示，确认后锁定日程并顺序执行。

日程中的压力按执行顺序变化。因此预览不能把每一槽都简单套用回合开始时的压力。首版可以先显示当前概率档与压力变化，不必制作复杂概率分布图。

空槽能否确认、同活动能否重复、材料何时锁定或扣除，见待决项。交互提案不能自行用“自动补齐”或“自动跳过”解决这些规则。

### 4.3 自由活动

入口显示活动名称、精力成本和可用状态；冒险额外显示本回合出发次数。活动不可用时显示具体原因，不弹出连续确认框。

自由活动与培养分开：点击普通自由活动不会占一个培养槽；确认培养也不会再次扣自由活动精力。洞天管理入口不显示精力价格。

### 4.4 确认边界

确认前只保留一个集中检查入口：

- 已知的不满足执行条件：展示原因并返回修改。
- 建筑未设置生产任务：提示清单，可前往处理，也可继续。
- 有生产任务但未派御灵：允许基础生产，不作为必须处理的错误。

提示必须发生在日程执行前。培养开始后不再补弹要求返回洞天的通知。重复点击确认只启动一次结算。

## 5. 洞天界面

### 5.1 布局与基本操作

以可直接操作的洞天地块为主体。工具区提供建造、道路、选择、移动；建筑目录按民居、生产、制造、景观分类；选中对象后显示其设置与本回合预测。

当前试作用等距投影表现地块，逻辑仍为原方格，不改变邻接与距离规则。未选中时收起建筑详情；选择模式选中建筑后展开配方和派工。建造模式保留完整地块、不因每次放置自动打开详情而移动画面。目录分类仍未实现，现为统一选择列表。

已确认的时序边界（2026-09-15）：洞天夜间画面只是场景表现，T1 教学和管理操作仍在确认日程前进行。进入夜间画面不推进回合、不执行培养或生产；确认日程后也不另开一轮洞天管理。

首版不以批量建造、蓝图复制、自动道路、完整撤销历史为前提。是否需要其中某项，后续用真实操作频率决定。

### 5.2 建造与移动

建造顺序：选建筑 -> 预览占地和成本 -> 选择位置 -> 校验 -> 确认建造 -> 设置生产与御灵。

- 已解锁且材料足够时可以当回合建好、安排并参与回合末生产。
- 预览至少区分位置合法与非法，说明占地、空间或资源问题。
- 民居、生产、制造显示入口道路连通状态，景观不因不邻路而报错。
- 移动显示原对象预览，确认后更新位置，取消不改变原位置。
- 移动保留已有等级、任务和御灵，不当作拆除后重建。

放置时是否允许临时断路、断路建筑是否停产、道路是否有成本，需要先定规则，不在 UI 中自行补齐。

### 5.3 生产与御灵

选中生产建筑后，按同一顺序展示：

1. 本回合任务或配方。
2. 预计消耗的已有库存。
3. 工作槽与各御灵适应性。
4. 基础产出、御灵贡献、景观贡献、最终预测。

玩家只在需要改变安排时操作。沿用上回合任务和分配，不每回合强迫重新派工。

御灵列表区分已收集、可入住工作、已分配；显示当前去向，避免看起来能在多个建筑重复工作。人口不足与跨建筑改派的具体处理仍需规则确认。

收益初步采用结果摘要加可展开明细，不默认开发布局推荐、全局最优排班和复杂分析图表。

### 5.4 库存与结算时序

当前库存和预计产出分开显示，预计产出不能出现在可使用物品数量中。

制造建筑选择配方时，不能把同回合末即将产出的新材料当成即时供应。配置资源冲突的提示方式须跟随最终缺料分配规则。

新建、移动、改派或切换配方后重新预测；预测没有执行扣费、生产或发奖的副作用。

作物教学已确认采用统一生产流程（2026-09-15）：T1 在确认日程前用清心草介绍种植与减压用途，产出仍在回合末入库，不因教程提前发放；T2 自由阶段安排青蕴草种植，回合末入库；T3 开始用节日剧情承接收获，开放音律日程。节日展示不再次增加青蕴草库存，不新增成熟倒计时或手动收获按钮。具体数量与节日消耗尚未确定。

## 6. 人物、装备与背包

人物页切换女儿与已解锁伙伴，复用属性和配置区域：

- A 与 B 分开显示，装备前后可比较，不把装备写进永久成长。
- 三件装备与六门功法使用固定槽位。
- 女儿主线门槛展示 A，不随临时换装虚增进度。
- 伙伴展示关系、可用功法和已知支线，不展示独立等级与经验条。

背包展示真实数量及适用操作。道具详情与送礼、培养成本、战斗栏使用同一个物品定义，避免不同页面各自解释效果。

出售、送礼、培养和生产如何竞争同一份库存，需要确定资源提交时机后再落地。不增加装备耐久、随机词缀洗练或背包重量系统。

## 7. 冒险与战斗

自由活动出发流程：目的地 -> 队伍与配置 -> 检查精力、出发次数 -> 出发 -> 路线节点。

- 目的地显示已知主要产物与对应剧情目标。
- 路线只允许选择当前可达的下一节点，不表现成必须清空的任务地图。
- 同一次冒险显示持续生命状态与已获得战利品。
- 战斗画面以自动战斗为主，提供暂停、倍速、共用四格物品栏。
- 物品栏同时表现库存、自身冷却与全局冷却；点击后按规则自动选目标，不增加第二次选人操作。
- 返回自由活动阶段后恢复队伍生命，不恢复已使用的物品。

真结局准备界面复用普通队伍配置区域，并展示 Boss 信息。正式开战确认是锁定属性快照的边界，不让 UI 预览本身重发奖励或刷新套组。

战前预览何时刷新、战败退出、主动撤退、跨节点冷却等未定问题不在本阶段生成多套交互分支。

## 8. 剧情与回合结算

剧情使用统一对话与选择界面。开始和结束阶段复用展示，但分别由相应主线、支线检查点触发。当前阶段决定故事表现版本，同一逻辑主线不会因换阶段再次发奖。

当前试作（2026-09-18）：已有全屏背景与立绘、下方整宽对话区、逐句推进和末句费用/奖励预告；长台词滚动，不挤走按钮。对话时阻止自由操作与下一回合，末句才记录完成；回合末读完自动回到札记。尚无选项分支、回看或任务日志，不能把上段目标交互理解为全部已实现。

结算顺序严格对应主体规则：

1. 顺序展示每项培养结果，A 与压力的变化可见。
2. 展示洞天消耗与产出，统一入库。
3. 检查并播放符合条件的主线升级剧情，显示真实扣除与下一回合开放内容。
4. 执行支线判断与相关反馈。
5. 应用已选择的回合末减压天赋，结束本回合。

结果可复用统一反馈区域，不为每种日程和每座建筑设计一套独立演出。动画节奏和是否逐项手动确认属于后续表现调优，不影响规则层只结算一次。

结局页面分别呈现人生结果与符合条件的结缘结果；禁用结缘的人生结局不显示一个误导性的“未达成恋爱”失败项。

## 9. 三条主体走查

### 9.1 培养与清心草

第 N 回合安排清心草生产 -> 确认日程并培养 -> 清心草回合末入库 -> 第 N+1 回合自由活动阶段使用减压 -> 确认新日程 -> 按降低后的压力判定培养。

若选择加工品，第 N+1 回合才可加工，第 N+1 回合末入库，第 N+2 回合自由阶段可使用。不会在生产批次内跨两层供应链。

### 9.2 冒险与洞天升级

冒险击败对应 Boss 获得关键物品 -> 当回合培养 -> 洞天资源入库 -> 升级条件满足 -> 扣除关键物品与资源并完成相应剧情 -> 下一回合使用新功能。

若经济功能已由继承获得，则按其规则只推进故事，不再次收取对应经济升级材料。

### 9.3 时间领先于洞天

女儿进入最后成长阶段，洞天仍在初级 -> 仍能安排培养、经营现有洞天、参与已开放活动 -> 生活结局按自身条件判断 -> 未满足洞天前置的主线路线保持未完成，不让整个回合流程卡死。

## 10. 本阶段不展开的交互

复杂小游戏、快速比赛模式、自动最优排班、批量编辑、图表分析、完整地图编辑器、复杂教程系统均不作为当前主体方案的必需项。

存档入口和允许保存的阶段属于主体待决项，需要与结算恢复方案一并确认，不默认为支持任意时点存档。
