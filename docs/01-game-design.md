# 主体设计基线

状态：汇总已确认规则。数值明确区分试算基线与示例；未完成的交互、公式和内容清单不在这里擅自补齐。

## 1. 游戏定位与范围

玩家以养父身份抚养女儿，同时经营洞天。女儿的属性、技艺、冒险和关系提供发展方向与解锁；洞天的资源、制品和布局收益反过来支持培养与冒险。

- 两条路线同等重要，但推进速度独立。进入最后成长阶段时，洞天仍可能停在初期。
- 一周目有资源与选择压力；多周目允许继承带来数值爆发，不普遍按女儿实力抬高敌人数值。
- 伙伴首先提供陪伴，不引入独立等级与经验刷取焦虑。
- 真结局保留最终挑战，但一周目不是设计为必败。
- 小游戏属于增强体验，不成为主体设计、开发和测试的范围扩张来源。

## 2. 身份、开场与成长阶段

养父是女儿父母的同门，是她的师叔，也是传授修行的师父，并非血缘叔父。玩家知道身份，女儿以父亲相称。

婴儿期以 2D 漫画交代：师叔历练归来发现宗门被灭，从外敌手中救下襁褓中的遗孤，重伤跳崖，隐居山村。后续村居、照料与背景铺垫通过对话表达，不继续扩成种植流程漫画。

成长阶段使用 4 岁、10 岁、16 岁三个内部标识，为剧情版本与图像资源服务。页面不显示具体年龄、年份或日期，不把阶段标识解释为逐年连续模拟。

| 项目 | 当前基线 | 状态 |
|---|---|---|
| 总回合数 | 60 | 试算基线，实际时长待原型验证 |
| 三阶段长度 | 12 / 24 / 24 回合 | 试算基线 |
| 阶段起始回合 | 1 / 13 / 37 | 由上述基线推导 |
| 季节 | 春夏秋冬，每回合轮换 | 已确认；具体界面表达另定 |

境界提升与成长阶段切换相互独立。

## 3. 回合顺序与三种安排

权威顺序：

回合开始主线判断 -> 支线判断 -> 自由活动与洞天管理 -> 确认日程 -> 顺序执行培养 -> 洞天生产入库 -> 主线剧情升级判断 -> 支线判断 -> 回合末天赋减压 -> 下一回合。

| 类型 | 使用什么额度 | 何时产生主要结果 |
|---|---|---|
| 女儿培养日程 | 培养槽，不扣自由活动精力 | 确认后按槽位顺序执行 |
| 女儿自由活动 | 自由活动精力；冒险另有出发次数 | 自由活动阶段 |
| 洞天管理与生产安排 | 不占女儿培养槽，不扣自由活动精力 | 管理即时生效，产出回合末入库 |

- 自由活动精力在回合开始恢复至上限，剩余不跨回合累积；上限和各活动成本待定。
- 默认 3 个培养槽。开局分配成就继承点可增加到 4、5 个，本局固定，下局可重新分配。
- 增加培养槽不增加自由活动精力或洞天结算次数。
- 确认日程后不再返回本回合自由活动阶段。
- 洞天的“夜间”仅为场景视觉表现，不构成独立行动阶段。T1 洞天教学及建造、派工等管理均在确认日程前完成；确认后先执行培养，再统一结算洞天生产（2026-09-15 确认）。
- 确认前提示未安排生产任务的建筑，允许返回调整，也允许忽略。无御灵但正在基础生产的建筑不算闲置。
- 普通与特殊日程复用同一流程。部分特殊日程可消耗灵石或材料，按活动配置；不为每个特殊日程额外开发专属系统。
- 中后期培养应包含吐纳类活动。各阶段完整日程名称、数量、收益尚未在本次文档中补齐。

## 4. 属性、装备、压力与心魔

### 4.1 属性口径

四个主属性各由四个细分相加，共 16 项：

| 主属性 | 细分 |
|---|---|
| 体魄 | 力道、根骨、身法、意志 |
| 道法 | 真元、术法、悟性、护体 |
| 仙缘 | 姿仪、人缘、礼节、运势 |
| 杂学 | 丹道、炼器、丹青、音律 |

- A：永久基础属性，来源包括初始值、培养、继承和永久成长。
- B：当前装备提供的属性，换装只改变 B，不写回 A。
- 装备仅武器、防具、饰品三个槽，只影响基础属性贡献，不扩充套装特效与主动技能系统。
- 故事的属性门槛读取 A。比赛读取 A+B。
- 真结局最终 Boss 复制战前确认时女儿的 A，然后使用自己的预设功法、装备。
- 永久属性成长不设固定数值上限。具体战斗属性换算和乘区顺序待定。

### 4.2 压力

压力范围 0 至 100，不自然降低，不因精力回满而降低。清心草及加工品可以减压；开局选择的部分天赋可在回合末减压。压力达到 100 不自动道陨，也不直接等同于心魔。

培养每项执行时按当时压力判定结果，该项改变的压力影响下一项。以下为已接受的试算方案：

| 执行前压力 | 大成功概率 | 成功概率 | 失败概率 | 期望倍率 |
|---|---|---|---|---|
| 0 <= P < 20 | 34% | 61% | 5% | 1.50 |
| 20 <= P < 50 | 22% | 63% | 15% | 1.30 |
| 50 <= P < 80 | 4% | 66% | 30% | 1.00 |
| 80 <= P <= 100 | 2% | 33% | 65% | 0.90 |

倍率为大成功 2.5、成功 1、失败 0.8。期望为三项概率与对应倍率乘积之和。这是理论期望，不含取整偏差，不代表已经试玩平衡；取整规则待定。

### 4.3 心魔与叙事状态

心魔是通过剧情与对话改变的低频状态，不再与压力共用 0 至 100 的同一条数值。真相知情与复仇倾向分别表达，知道真相或选择复仇不自动等于邪恶或心魔加深。具体状态表、变化条件待剧情配置。

## 5. 两条路线的互相支持

洞天解锁与进度由父亲恢复及剧情推进，女儿属性数值不直接作为洞天解锁条件。女儿通过比赛、冒险、人物事件提供图纸、物品与剧情反馈；御灵解锁由父亲线或剧情承载。此处同步 GDD v2 §7.1 已明确的方向，具体触发节点仍待配置。

| 女儿提供给洞天 | 洞天提供给女儿 |
|---|---|
| 活动与际遇带回剧情事件和解锁资源 | 御灵工作后提高资源产出 |
| 四艺比赛获得图纸、资源与称号 | 建筑生产礼物、培养消耗品、战斗物品 |
| 冒险 Boss 提供关键剧情物品 | 生产基础材料，支持父亲恢复与洞天解锁 |
| 角色关系与支线开放能力 | 礼物提升好感，支持伙伴陪伴和支线推进 |

不能据此强制两条路线同步升级。部分入世、生活方向结局不要求洞天进度；复仇、真结局等主线方向要求相应洞天进度。只有真结局挑战复制属性的最终 Boss。

## 6. 洞天经营

### 6.1 建筑、道路与空间

| 类别 | 例子 | 职责 |
|---|---|---|
| 民居 | 各规模住所 | 提供入住工作人口容量 |
| 生产 | 农田、矿洞、养殖场、林场、捕鱼场、灵田 | 按建筑产出基础资源或药材；两类物品分开归类 |
| 制造 | 丹炉、铁匠铺、制符室 | 消耗已有材料制造产品 |
| 景观 | 稻草人、湖泊等 | 对适用建筑提供加成 |

- 民居、生产、制造建筑须邻接道路，且道路网络连通洞天入口；景观不要求邻路。
- 建筑与景观可自由移动，保留等级、生产设置、御灵分配，并重新计算连通性和收益预测。
- 不等待施工。有空间、解锁和资源，当回合建造并安排后即可参与该回合生产。
- 建筑生产任务和御灵分配跨回合保留，直到玩家修改。
- 御灵总收集量不受民居限制；民居限制入住并参与工作的数量。
- 地块格制、建筑占地、邻接度量、断路后状态、拆除返还与人口超限处理尚未定案。

### 6.2 御灵与加成

- 御灵通过女儿养成相关剧情解锁、获得，部分已解锁御灵可购买。
- 每只御灵同一回合只负责一份工作。小、中、大型建筑通常分别容纳 1、2、3 只。
- 适应性影响单位投入对应的产出比例，不另设工作经验养成。
- 每只御灵的适应性贡献作为独立乘区；未派御灵仍有建筑基础产出。
- 景观按距离衰减。相同词条的贡献在同一乘区内相加，不同词条使用独立乘区相乘。
- 先对各景观贡献做距离衰减，再按词条分组。最终衰减曲线、适应性映射和取整待定。
- 界面须能预测当前安排的产出，但不能把预测直接当成已入库物品。

### 6.3 生产与库存

产出分类已确认（2026-09-15）：灵田只产出药材，药材不属于基础资源。“基础药材”描述青蕴草在药材中的定位，不将其归入基础资源；灵田也不承担食材、茶礼或染料等非药材作物的生产。物品分类不改变回合末统一生产入库的流程。

物种与用途已确认（2026-09-15）：青蕴草和清心草是两个独立物种。青蕴草属于基础药材，秋季节日是其已讨论的剧情用途；清心草用于降低压力。两者分别定义物品与库存，不合并为同一种物品，也不默认互相替代。具体加工配方、成本和产出仍待确认。

洞天每回合末统一结算，不允许同一结算批次中即时串联加工：

- 第 N 回合生产的药草，回合末入库。
- 最早第 N+1 回合加工，成品在第 N+1 回合末入库。
- 本回合刚入库的资源，可以参与随后进行的主线升级条件判断。
- 常规制品可以自用、送礼或出售换灵石。可购买基础材料和部分已解锁御灵，不要求玩家建齐全部产业。
- 缺料时优先分给谁、是否预留材料、多个建筑如何竞争库存，仍是待确认的主体规则。

教学段已确认时序（2026-09-15）：T1 在确认日程前通过清心草教学引入洞天生产与减压用途；T2 自由阶段安排青蕴草种植，T2 回合末随洞天生产统一入库；T3 回合开始承接收获触发秋季节日剧情，开放音律日程。节日不重复发放收成，不增加成熟倒计时或手动收获步骤。种植成本、产出数量及节日是否消耗青蕴草仍待配置与确认。

内容分工已确认（2026-09-15）：助手搭建配置与通用流程，用户依据示例自行扩充药材、配方、数值和文案，不再逐项确认内容条目。当前以清心草、青蕴草种植及清心丹加工验证骨架；示例不限定青蕴草必须作为通用辅材。填写方法见 [06 内容填写指南](06-content-authoring.md)，实际功能见 05。

### 6.4 父亲恢复、解锁与继承例外

通常由女儿冒险获得特定剧情物品，再结合基础资源，在回合末生产入库后自动检查。满足条件则触发对应升级剧情并实际扣除所需物品与资源，新功能和建筑解锁从下一回合可用。

土地大小、建筑图纸、故事进度分别记录：

- 图纸是建造资格，不是消耗品；获得后可重复用于建造，不另外收取图纸解锁材料（2026-09-18 确认）。每栋建筑仍支付自身建材成本，且必须满足现有土地的空间与布局条件。
- 仅继承高级图纸：允许在现有空间与资源条件下造高级建筑，土地仍按剧情扩展。
- 仅继承土地：提前使用空间，高级图纸仍待解锁。
- 两者均继承：对应 Boss 仍可承担故事推进，但不为已经继承的经济解锁再次收取升级材料。
- 建造建筑本身的成本仍然存在，不因继承图纸而免费。

## 7. 剧情与境界

女儿的境界是主线进度名称，不另做独立经验条、熟练度或消耗精力的破境行动。四维 A 合计超过相应阈值可触发突破主线，例如大于 1000、2000、4000；这些数值是示例，不是已定最终门槛。触发任务不等于自动完成任务。

- 主线有前置顺序、可触发时段、排除时段、并发或互斥标记。
- 不是统一限制每回合只能触发一条主线。
- 每个主线逻辑节点都有 4 岁、10 岁、16 岁三份剧情与立绘版本。
- 三份版本共用同一逻辑节点、属性条件、解锁奖励和本局完成记录。
- 4 岁阶段可以达到金丹；之后进入 10 岁阶段不会再完成一次相同的金丹节点。
- 阶段与境界是两个独立状态。表现版本随当前阶段选择，不通过重复发奖励来换立绘。
- 支线需要多少阶段变体尚未明确，不自动按主线三倍扩充。

主线数量为 N 时，需要规划 3N 份主线表现内容；这是内容与美术工作量，不是三套剧情代码。

2026-09-18 执行试作边界：用户要求继续后，按“最后一句确认才完成节点并扣费、发奖，再重查同类后续”接入原型；检查点先主线后支线，支线新满足的主线留到下一检查点。当前包含线性对话、物品变化、活动与图纸解锁，尚不代表升级并发组、父亲恢复与土地继承减免或复杂任务完成条件已定案。活动与普通图纸奖励可配置即时/下回合生效，不改变父亲恢复升级应下回合生效的规则。

## 8. 冒险与战斗

### 8.1 冒险

- 10 岁阶段开放；最多三人组队。
- 先选择已解锁目的地，再进入该目的地的随机分支路线。
- 默认每回合出发一次，指定开局天赋可增加到两次，每次出发消耗精力；不按节点再次收精力。
- 试算路线长度为实际经过 5 至 7 个节点，包含终点 Boss，不要求清空分支地图。
- 节点包括普通怪、精英怪、资源点、特殊事件；关键剧情物品来自相应 Boss。
- 战败保留此前已获得战利品，不返还出发次数与精力，未击败 Boss 不得其奖励。
- 同次冒险中生命值跨节点延续，可由物品、事件恢复；返回自由活动阶段后队伍恢复生命，已消耗物品不返还。
- 默认在回合开始决定地图种子；可配置读档时为尚未开始的地图重新生成种子。已经开始的冒险须恢复原地图和进度。

目的地与第二次出发的种子派生、战斗间冷却重置、倒地复活与主动撤退细则待定。

### 8.2 战斗与功法

采用可暂停的半即时自动战斗。普攻自动，外功按独立冷却自动释放；玩家手动使用物品，目标按物品定义自动选择。暂停冻结战斗时钟，倍速同步推进战斗时钟。

| 槽位 | 数量 | 主要作用 |
|---|---|---|
| 外功 | 2 | 伤害乘区与效果 |
| 内功 | 2 | 被动与基础属性乘区 |
| 轻功 | 1 | 速度、闪避加法区 |
| 杂学 | 1 | 主动物品使用效率 |

女儿与伙伴共用槽位规则。伙伴通过自己的支线解锁更高级功法，不做秘籍全队通用和复杂熟练度。女儿功法可配置主线、冒险、人物事件等解锁来源，不按类别硬绑定唯一来源。

### 8.3 物品

- 全队共用四格物品栏，按实际库存个数消耗。
- 来源包括事件强力物品、洞天产品、战斗材料与普通物品。
- 每种物品有自身冷却，物品栏另有全局冷却，防止四格瞬间连续使用。
- 道具自动作用于定义的目标，例如最低生命角色或全体，不再增加手动点选目标步骤。
- 没有相关称号、杂学加成时，物品仍按基础效果使用。
- 队员对应杂学可以贡献物品加成，相同词条相加。
- 额外触发按附加效果次数相加，只消耗一次物品、启动一次冷却，不递归触发更多次数。
- 免耗概率按适用类别叠加，上限 100%；每次主动使用只判定一次，免耗仍有冷却。
- 免耗只是不扣库存，不能复制、新增或通过返还制造额外物品。

空库存能否触发免耗、重复道具槽、目标比较方式和冷却跨战斗规则待定。

### 8.4 真结局 Boss

战前准备可查看敌人属性与关键能力。正式确认时，锁定女儿 A 的复制快照及 Boss 预设套组；Boss 功法和装备由协调好的预设套组随机选取，不复制女儿 B。

准备阶段允许调整阵容和配置，不把反复换装备设计成无提示刷新 Boss 套组。预览刷新范围与套组读档随机规则仍需明确。普通敌人不使用这套复制机制。

## 9. 伙伴、关系与结局

- 计划六名可攻略角色，三男三女。
- 伙伴不跟随女儿数值自动同步，允许掉队；通过支线获得阶段性属性和功法提升。
- 不做独立等级、经验或刷战斗次数的伙伴养成。
- 结缘由好感判断，不强制绑定伙伴战斗成长线的完成度。
- 人生结局与结缘结局分别结算；部分特定人生结局不触发结缘。
- 保留预设多人结缘组合，不是任意合格人物自动拼成组合。
- 结缘按已讨论的最高合格好感角色与预设组合匹配思路处理，符合条件的对应多人组合优先于单人结果；平分、重叠组合和具体名单待定。
- 生活类结局可不要求洞天进度；主线相关路线按各自条件要求洞天进度。

具体结局数量、名单、优先级和禁用结缘的结局仍待确认。

## 10. 四艺比赛：保留奖励链，后置复杂玩法

四艺培养用日程槽；比赛属于消耗精力的自由活动，不占培养槽。由于自由活动先于培养，本回合新培养的属性最早帮助下一回合比赛。

- 四艺比赛按春夏秋冬轮流开放，具体对应关系待定。
- 赛事档次由对应技艺属性决定，不强制按成长阶段锁定。
- 参赛与数值表现采用 A+B，允许高养成、好装备带来明显优势。
- 评分原则：属性基础分 + 小游戏表现加分。操作失误不倒扣属性基础分。
- 资源、图纸、称号构成比赛奖励；对应称号可解锁杂学，强化洞天生产物品的战斗效果。
- 属性到分数的公式、加分上限和各档获奖条件待定。
- 暂不增加跳过小游戏、快速结算等额外模式。

已确认的炼丹方向：各炉区独立变化，玩家一次调控一个，所有炉区同时运行，需要轮流维持各自适宜区间；初级一个，高级可到两个或三个。A+B 丹道影响操作容错。各档复用同一逻辑并配置参数。

其他小游戏属于锦上添花。本阶段不继续展开独立机制或按四个完整小游戏估算主体开发量，也不因此删除四艺的培养、比赛奖励与洞天解锁关系。

## 11. 成就与开局继承

成就获得继承点预算，每个新周目重新选择分配，本局与其他局独立；不是一次性永久消费点数，也不是直接复制上一局完整库存。

- 可分配属性、土地、图纸、御灵、资源、天赋、额外培养槽等。
- 成就可解锁可选词条，开局花预算选择后才在本局生效，暂不做局内天赋树。
- 已经开始的局不因之后获得的新成就自动增加能力。
- 土地、图纸和剧情分别保存，按第 6 节处理继承例外。
- 具体成就、成本、互斥组、预算上限和失败局收益待定。
