## 1. 核心乐趣假设（Fun Hypothesis）

> 你在有限的修仙岁月里，通过一次次培养决策，看着一个有灵根的小女孩从凡俗一步步修成仙——她的境界、技艺、气质、羁绊都随你的选择实时变化，产生「她是我一路养大的」养成感，以及「成长可见」的满足感。

一句话拆成两个可验证的假设：
- **H1（养成感）**：玩家对女儿产生「她是我养大的」情感依附，其强度与「成长被看见的频率」正相关。
- **H2（剧情张力）**：「师叔伪装为父 + 灭门血仇」这条暗线，会在真相揭晓时制造本作最强的情感爆发。

**H1 失败信号**：玩家 10 分钟内在没有新的「女儿变化」反馈时流失 → 反馈通道太慢。
**H2 失败信号**：真相揭晓时玩家无情绪波动（既不愤怒也不心疼）→ 铺垫不足或视角错位。

## 2. 设计支柱（冲突时按序优先）

| # | 支柱 | 一句话判据 |
|---|---|---|
| 1 | 成长可见 | 每次培养动作，玩家立刻看到「她变了」 |
| 2 | 选择有分量 | 每次日程安排改变成长方向，没有无效选择 |
| 3 | 境界突破的爽感 | 突破是阶段性大反馈（立绘换装/解锁功法/剧情） |
| 4 | 羁绊深化 | 情缘从生疏到同心，是核心情感反馈 |
| 5 | 多结局重玩 | 不同路线导向不同道途，二周目继承 |

## 3. 视角与世界观

### 3.1 视角叙事（定稿）

你是青云宗二师兄，长年在外历练。你回宗那日，看见的是满门尸首——宗门一夜被屠尽。你在废墟里发现大师兄与小师妹襁褓中的女儿尚存一息。为从仇人手中抢下孩子，你以一敌十硬接数剑，金丹碎裂、境界跌回炼气，抱着孩子杀出重围，隐姓埋名躲进边陲小城，以「父女」身份相依为命——一对凡人父女，是这修仙界里最不引人注目的存在。

你拖着残躯打零工、上山采药糊口，也在她长到能握剑的年纪，偷偷把第一本功法塞进她手里。她叫你「爹」，你却是她素未谋面的师叔；你教的每一句口诀，都压着她父母的命，和你不敢说出口的真相。

游戏从她初入仙途开始，到她在你引导下拜入宗门、最终道成独立为止。满门被屠的真相随她成长一点点揭开——那个你拼命躲的仇人，终会找上门来。

### 3.2 时间框架（游戏内时间轴）

| 女儿年龄 | 阶段 | 关键节点 |
|---|---|---|
| 10-11 岁 | 凡俗启蒙（家教阶段） | 你偷传第一本功法，她练气入门 |
| 12 岁 | 拜入宗门（主线转折） | 你送她拜入小门派，身份半暴露风险 |
| 13-14 岁 | 练气→筑基 | 宗门成长，灭门真相初现线索 |
| 15-17 岁 | 筑基→金丹 | 仇人踪迹渐明，决战前夜 |
| 18 岁 | 道成独立（主线收束） | 结局判定 |

> 单局时长目标 6-10 小时。8 年 × 12 月 = 96 个「行动月」。每月为一个回合，回合开始恢复 10 点父女共享精力；玩家可在月内安排多项行动，主动结束本月后统一结算家用与时间推进。

## 5. 属性体系

### 5.1 四大主属性（各由 4 项细分相加，共 16 项）

| 主属性 | 细分（职责） |
|---|---|
| 体魄（身） | 力道(攻) · 根骨(抗) · 身法(速) · 意志(外防) |
| 道法（法） | 真元(威) · 术法(攻) · 悟性(成长杠杆) · 护体(防) |
| 仙缘（缘） | 姿仪(仪) · 人缘(交) · 礼节(礼) · 运势(运) |
| 杂学（艺） | 丹道(炼丹) · 炼器(炼器) · 丹青(符画) · 音律(乐道) |

- 每项细分 0-100，主属性 = 4 细分之和（0-400）。
- 主属性用于结局判定与事件门槛；细分用于战斗/技艺的具体结算。

### 5.2 横切属性

| 属性 | 含义 | 范围 |
|---|---|---|
| 情缘 | 父女/师徒羁绊 | 0-100 |
| 修为境界 | 练气→筑基→金丹→元婴→化神 | 5 阶 |
| 心魔 | 女儿压力/执念状态 | 0-100（超限负面） |
| 精力 | 父女共享的月内行动点数 | 每月恢复至上限 |
| 灵石 | 货币 | 无上限 |

### 5.3 先天属性

- **灵根**（金/木/水/火/土 + 变异/天灵根/杂灵根）：决定初始成长率与可修功法方向，**不可培养、不可变**。开档随机/自选，对应原作「星座/血型」位。

### 5.4 主角隐藏值（双轴）

- **复仇倾向**（0-100，低值代表放下/克制，高值代表追索血仇）
- **真相公开度**（0-100，代表女儿对身世与灭门真相的知情程度）
- 两轴相互独立：坦白不必然导向复仇，隐忍也不等于持续欺瞒。
- 改变方式：父女对话、追查旧案与关键剧情选择。
- 影响：结局分支、主线分岔、父女羁绊与身份暴露风险；界面仅展示描述，不直接显示数值。

## 6. 系统设计（每系统：目的 / 输入 / 输出 / 边界 / 失败状态）

### 6.1 日程系统
- **目的**：让玩家每月做一组「培养决策」，是养成感的第一入口。
- **输入**：每月 10 点父女共享精力 + 可用活动列表（随阶段/地点/境界解锁）。
- **输出**：属性增减、材料/灵石、境界条、心魔变化、情缘变化、事件触发。
- **活动归属**：女儿行动（修炼/历练/技艺/社交）、父亲行动（重修/采集/打工）、共同行动（谈心/追查/休息）均消耗同一精力槽。
- **父亲洞天种田**：父亲重返筑基后解锁，是一项独立行动，消耗共享精力并产出灵药。
- **边界**：精力每月恢复至上限；部分食物/休息可有限恢复；同一活动连续做有边际递减（防止无脑刷）。
- **失败状态**：精力耗尽仍想行动 → 提示「精力不足」；心魔过高时部分活动被锁（如闭关效率减半）。

### 6.2 时间主线系统（参考《火山的女儿》勇者线）
- **目的**：用固定时间节点驱动剧情，让养成有方向、有张力。
- **输入**：当前年份 + 女儿境界 + 父亲复仇倾向 + 真相公开度 + 女儿心魔。
- **输出**：主线剧情推进、分支走向、仇人动态。
- **节点**：第1年（身世伏笔）→ 第3年（拜入宗门）→ 第5年（真相线索）→ 第7年（仇人现身）→ 第8年末（收束判定）。
- **分岔规则**：每个节点按「境界门槛 + 复仇倾向 + 真相公开度 + 心魔」组合决定进入哪条分支（详见 §9）。
- **失败状态**：境界/心魔不达标 → 进入「被保护/回避」分支，错过关键信息，影响结局。

### 6.3 境界系统
- **目的**：提供「成长可见」的最强反馈——突破。
- **输入**：境界条（修炼/历练累积）+ 突破材料（丹药/灵石）+ 悟性门槛。
- **输出**：境界提升、立绘换装、解锁功法/活动、属性上限提升。
- **边界**：练气→筑基→金丹→元婴→化神 5 阶；修为圆满后仅解锁「突破」行动，不自动结算；突破行动消耗共享精力与材料，失败概率与心魔、悟性负相关。
- **失败状态**：突破失败 → 境界条回落、心魔上升、材料消耗（有代价，不是纯惩罚）。

### 6.4 事件系统
- **目的**：打破「纯刷数值」的单调，制造意外与选择。
- **输入**：随机种子 + 触发条件（境界/属性/日期/关系/复仇倾向/真相公开度）。
- **输出**：剧情文本 + 选项 + 属性/关系/主线值变化。
- **边界**：随机事件与主线事件分离，主线事件不可跳过。
- **失败状态**：选项导致的负面结果（心魔增、情缘降）——有后果的选择才是选择。

### 6.5 羁绊系统
- **目的**：承载「父女情」这条情感主线。
- **输入**：父女对话、共同行动（游历/教导）、关键选择。
- **输出**：情缘值 + 关系层级（生疏→相依→同心）。
- **边界**：情缘上限 = 亲情与传承，**永不到「道侣」**；恋爱线（道侣）是女儿与 NPC 的独立关系。
- **失败状态**：长期不互动 → 情缘停滞；隐瞒/欺骗选择 → 情缘下降。

### 6.6 技艺系统（杂学四艺）
- **目的**：给「杂学」维度实打实的玩法承载（生产→加工→出售）。
- **输入**：材料 + 精力 + 技艺阶位。
- **输出**：丹药/法宝（成品）+ 技艺经验。
- **阶位**：每艺「入门→小成→大成→圆满」四阶，每阶解锁新配方/新能力。
- **失败状态**：材料不足/阶位不够 → 无法制作；制作有成功率（与阶位正相关）。

## 7. 养成感设计（四抓手）

| 抓手 | 机制 | 落地 |
|---|---|---|

## 8. 经济系统（Sources & Sinks）

### 8.1 闭环

```
父亲生产（种田/采药/狩猎）───┐
                              ├─→ 材料 ─→ 炼丹/炼器 ─→ 丹药/法宝 ─→ 自用（女儿突破/装备）
女儿打工（历练/宗门任务）→ 灵石 ─┘                                    └→ 出售（换灵石/关键资源）
     ↓
 家庭共有金库（父亲统一支配）
```

### 8.2 Sources

| 来源 | 产出 | 时机 |
|---|---|---|
| 父亲生产（种田/采药/狩猎） | 材料（凡俗药材→灵药→妖兽材料，随剧情升级） | 全程 |
| 女儿打工（历练/宗门任务） | 灵石 | 拜入宗门后为主 |
| 出售材料/成品 | 灵石 | 全程 |
| 宗门俸禄 | 灵石 | 拜入宗门后 |
| 奇遇 | 灵石/稀有材料 | 随机 |

### 8.3 Sinks

| 消耗 | 说明 |
|---|---|
| 日常开销 | 父女生活成本（固定月开销） |
| 功法秘籍 | 女儿学新功法 |
| 法宝材料 | 炼器所需 |
| 突破所需 | 突破丹药/材料 |
| 炼丹炼器消耗 | 材料+精力 |

### 8.4 平衡要点（防通胀）

1. 材料产出须有成本（消耗精力/受季节地点限制）。
2. 成品权衡「自用 vs 出售」。
3. 父亲生产与女儿打工收益互补（父亲产材料、女儿产灵石）。
4. 按阶段（凡俗躲藏期/宗门后/独立期）分收支曲线。

## 9. 结局设计（12 结局 + 判定骨架）

### 9.1 结局列表（按道途分类，无正邪二元）

| 结局 | 道途 | 主要判定 |
|---|---|---|
| 飞升（隐藏） | 境界 | 化神 + 关键机缘 |
| 重建宗门 | 传承线终点 | 复仇倾向低 + 真相公开度高 + 情缘高 + 关键事件 |
| 一宗之主 | 权力/声望 | 境界 + 礼数 + 名望事件 |
| 丹王 | 技艺 | 丹道圆满 + 关键作品 |
| 炼器宗师 | 技艺 | 炼器圆满 + 关键作品 |
| 乐道仙 | 技艺 | 音律圆满 + 关键事件 |
| 散修 | 自由 | 境界中 + 无宗门归属 + 关键选择 |
| 归隐 | 克制线终点 | 复仇倾向低 + 情缘高 |
| 道侣 | 恋爱线 | 女儿与 NPC 关系达道侣 + 关键事件 |
| 复仇雪恨 | 血仇线 | 复仇倾向高 + 境界高 + 主线收束 |
| 道陨（失败） | 悲剧 | 心魔失控/突破失败累积 |
| 传道授业 | 传承线另一形态 | 复仇倾向低 + 真相公开度高 + 礼数/人缘 + 关键事件 |

### 9.2 判定公式（骨架）

```
结局 = 主属性最高项 + 境界 + 心魔 + 复仇倾向 + 真相公开度 + 关键事件 + 羁绊
优先级：即时失败（道陨）> 境界类（飞升）> 主线类（复仇/重建/归隐）> 技艺类 > 情感/自由类
```

### 9.3 时间主线分岔（关键）

| 节点 | 分岔判据 |
|---|---|
| 第3年·拜入宗门 | 境界达标→正式拜入；不达标→被拒/沦为杂役 |
| 第5年·真相线索 | 主动追查→危险+信息并提高复仇倾向；向女儿坦白→提高真相公开度；回避→安全但错过信息 |
| 第7年·仇人现身 | 境界+心魔决定「能否自保/护女」 |
| 第8年末·收束 | 复仇倾向 + 真相公开度 + 情缘 + 境界 → 复仇/重建/归隐三线最终判定 |

## 6. 压力与心魔

- 压力 0-100：不自然降低、不随精力回满降低；达 100 不自动道陨。清心草及加工品可减压；部分开局天赋回合末减压。
- 培养逐项按**当时**压力判定，本项压力变化影响下一项。已接受试算：

| 执行前压力 | 大成功 | 成功 | 失败 | 期望倍率 |
|---|---|---|---|---|
| 0–19 | 34% | 61% | 5% | 1.50 |
| 20–49 | 22% | 63% | 15% | 1.30 |
| 50–79 | 4% | 66% | 30% | 1.00 |
| 80–100 | 2% | 33% | 65% | 0.90 |

倍率 2.5 / 1 / 0.8；取整偏差未含，取整规则待定。**验证路径**：D1 已实现该判定；取整后实际期望 + 清心草供需是 04 §4 列明的验证项。

**定位口径（2026-09-10 确认）：常驻小维护**。增速维持现状试算（每槽 +5~12、3 槽 +15~24/回合，初始压力 12）：压力是每回合都要看一眼的水位，草为常备消耗品；不管减压则 4-5 回合沉底。两条已知代价与观察项：

1. 「吃草」可能退化为无脑仪式动作。playtest 盯一个信号：**玩家吃草前是否看过档位边界（20/50/80）**——从不看说明决策密度塌陷，优先调草的稀缺性（产能/库存），不动增速。
2. 供应链成熟后产能（药田 4~6 草/回合）远超减压需求（约 1 棵/1-2 回合）。草过剩不是 bug，是供给升级的体现——允许过剩流入丹（-50）、礼物链等其他用途即可。

附观察（非设计承诺）：一档（<20）开局排程后即不可达（12+15 起跳），而丹 -50 可从 ~60 直接打回一档——「一档要靠供应链买回」是现状数值里自然长出来的弧线，若试玩中玩家自发感知到，可考虑后续显性化。

- 心魔：剧情与对话改变的**低频叙事状态**，不与压力共用数值。真相知情与复仇倾向分别表达；状态表与变化条件待剧情配置。

### 叙事渗透：暗线接入玩法规则（B 方案，2026-09-10 修订定稿；接口为提案，数值依赖 C06 与剧情配置）

**渗透原则**：只通过**可见载体**渗透——活动属性、物品需求、好感门槛，三类玩家看得见、读得懂的载体；**禁止隐藏参数修正**（暗改概率/档位/增速只制造挫折感，2026-09-10 否决先例见下）。每个渗透点保持双路径。

| # | 载体 | 规则 | 制造的新玩家决策 |
|---|---|---|---|
| 1 | 复仇倾向 → 特殊活动 | 复仇线解锁「恨意淬体」类修炼：活动**自带**高成长、高压力属性，数值写在活动详情里直接可见；复仇倾向本身不修改任何养成数值 | 培养形状取舍：效率换压力，摆在明面上选 |
| 2 | 主线 → 洞天产出要求 | 需要洞天进度的主线方向（复仇/真结局，01 §5 已确认）在剧情节点要求特定洞天产出（如突破丹、特定制品）；需求提前明示，玩家有准备窗口；生活类结局不挂产出要求 | 为推进剧情而生产：叙事成为洞天的需求侧拉力 |
| 3 | 配角交互 → 心魔 | 与配角（伙伴）交互降低心魔（心魔是剧情低频状态，配角交互是其主要平复通道之一）`[P]`；不与压力数值合并 | 心魔平复走社交叙事通道，不走吃丹吃药 |
| 4 | 好感门槛 → 配角剧情 | 配角好感达阈值解锁配角支线剧情 `[P]` | 叙事内容量的主要扩容入口，也是接口 3 的回报端 |

**被否决接口（存档记录，不复活）**：① 心魔收窄压力档位边界——不可直观展现，概率暗调只产生挫折；② 真相知情衰减人际减压——未采纳，减压经济保持由精力稀缺与供应链成熟驱动，不叠加叙事惩罚。

**设计说明**：四个接口全部复用既有系统（活动表、产出/剧情检查、好感、支线），不新建数值框架；接口 2 使叙事成为咬合的需求侧驱动轮（主线要产出 → 玩家有理由经营），与压力侧拉力（女儿要减压 → 玩家有理由种草）互补，一推一拉。旧版「心魔 0-100 与压力共数值」不复活。

## 8. 洞天经营

- 建筑四类：民居（容量）、生产（基础资源）、制造（消耗材料出产品）、景观（加成，不要求邻路）。
- 民居/生产/制造须邻接有效道路且连通入口；建筑与景观可自由移动并保留等级、任务、御灵分配。
- 无施工等待：有空间、解锁和资源，当回合建造安排即可参与生产。任务与派工跨回合保留。
- 御灵：同一回合只负责一份工作；小/中/大建筑容纳 1/2/3 只；适应性影响产出比例，无工作经验养成；每只独立乘区；未派工有基础产出。
- 景观：距离衰减后按词条分组，同词条相加、异词条相乘。衰减曲线、适应性映射、取整**待定**。
- 生产时序：回合末统一结算，**禁止同批次串联加工**——第 N 回合产出入库，最早 N+1 回合加工。
- 预测必须即时反映当前安排，但预测不等于已入库物品。
- 缺料分配（优先级/预留/竞争）是 **C02 待定**；D2 临时口径「按建筑 ID 从小到大、缺料整单停产」仅试作。
- 父亲恢复/解锁：冒险关键物品 + 基础资源，回合末入库后自动检查，触发即扣料，下回合可用。
- 继承例外：土地、图纸、故事三记录分离——继承高级图纸仍按剧情扩土地；继承土地仍待解锁图纸；两者均继承时 Boss 只推进故事、不二次收取经济升级材料；建造成本照付。
- 格制、占地、断路状态、拆除返还、人口超限处理是 **C03 待定**。

## 9. 剧情与境界

- 境界 = 主线进度名称，无独立经验条、无熟练度、无消耗精力的破境行动。
- 四维 A 合计过阈值可触发突破主线（示例 1000/2000/4000，非定案）；触发 ≠ 完成。
- 主线节点有前置顺序、可触发/排除时段、并发或互斥标记；不限制每回合只触发一条。
- 每个逻辑节点配 4 岁/10 岁/16 岁三份表现（剧情+立绘），共用逻辑、条件、奖励、完成记录；不因换阶段重复发奖。
- 4 岁阶段可达金丹；同节点跨阶段不重复完成。
- 触发后何时完成、多项同时满足如何处理、成本拆分是 **C04 待定**。

## 10. 冒险与战斗

### 10.1 冒险
- 10 岁开放；最多三人组队；默认每回合出发一次（天赋可到两次），每次消耗精力，不按节点再收。
- 流程：选目的地 → 该目的地随机分支路线 → 5-7 个实际节点（含终点 Boss），不清图。
- 节点类型：普通怪、精英怪、资源点、特殊事件；关键剧情物品来自对应 Boss。
- 战败：保留已获战利品，不返还出发次数与精力；未击败 Boss 不得其奖励。
- 生命跨节点延续（物品/事件可恢复）；返回自由活动阶段后队伍恢复生命，已耗物品不返还。
- 地图种子回合开始决定；已开始的冒险须恢复原地图与进度；种子派生细则**待定**。

### 10.2 战斗
- 可暂停半即时自动战斗：普攻与外功自动（外功独立冷却），玩家手动用物品（自动选目标）；暂停冻结战斗时钟，倍速同步推进。
- 槽位：外功×2、内功×2、轻功×1、杂学×1；女儿与伙伴共用规则。
- 伙伴功法经自己支线解锁；女儿功法来源=主线/冒险/人物事件，不按类别硬绑。
- 物品：全队共用四格栏；每种物品自身冷却 + 物品栏全局冷却；免耗概率按类别叠加上限 100%，每次使用判一次，免耗仍有冷却，不复制不返还。
- 待定：空库存免耗、重复道具槽、目标比较、冷却跨战斗规则。

### 10.3 真结局 Boss
- 战前可查看敌人属性与关键能力；确认时锁定女儿 A 快照；Boss 从协调好的预设套组随机选取功法与装备，不复制 B。
- 准备阶段可调整阵容配置；不把反复换装设计成无提示刷新套组；预览刷新范围**待定**。普通敌人不用此机制。

## 11. 伙伴、关系与结局

- 六名可攻略（三男三女）。伙伴不随女儿数值自动同步，允许掉队；经支线获得阶段性属性与功法提升；**无独立等级、经验、刷战斗次数**。

- 生活类结局不要求洞天进度；主线相关路线按各自条件要求。
- 不沿用旧版十二结局表；数量、优先级、禁用结缘名单待定。

## 12. 四艺比赛

- 四艺培养用日程槽；**比赛是消耗精力的自由活动，不占培养槽**。
- 按春夏秋冬轮流开放（对应关系待定）；赛事档次由对应技艺属性定，不按阶段锁。
- 参赛与数值用 A+B；评分 = 属性基础分 + 小游戏表现加分，操作失误不倒扣基础分。

- 炼丹小游戏方向已确认：各炉区独立变化，一次调控一个、全部同时运行，轮流维持各自适宜区间；初级一个炉区，高级可到 2-3 个；A+B 丹道影响容错；各档复用同一逻辑配置参数。

## 0. 结论（先读这里）

**判定：结构成立，灵魂未证。可以做下去，但在 H1 得到实证之前，不投入内容生产。**

四条结论，按分量排序：

1. **这游戏成不成，取决于一件事：齿轮咬合（H1）能不能被玩家感知。** 咬合做出来，它是「一个有经营杠杆的养成游戏」，差异化成立；做不出来，它就是两个平庸游戏（普通养成 + 普通农场）硬拼在一个窗口里。当前所有证据里，即时层和单局层的钩子链是完整的，D1/D2 也跑通了最小闭环——但咬合恰好是唯一没有实证的核心假设：交换事件没有分布表，且原型里女→洞的事件反馈（比赛图纸、冒险物品）完全缺席。（2026-09-10 修正：三主体结构——洞天由父亲解锁，女儿属性数值不做洞天门槛，女→洞只走事件，单向教学段是设计意图而非缺陷。）
2. **压力不是赌局，是物流——这要认。** 清心草使用精力成本为 0，所以「高压力还敢不敢排培养」实际上等于「草的库存够不够」。决策压力从女儿侧转移到了洞天供应链。这符合 H2 的设计意图（压力是咬合的最小单位），但它意味着压力系统不提供赌博式的刺激感，它的职责是给洞天存在理由。别指望它制造心跳，别按「刺激」的方向调它，按「供需」的方向调它。
3. **最大的暗雷不是机制，是叙事缺席。** 新基线 18 节 GDD 里叙事只占半节；对标《火山的女儿》，那个品类的胜负手恰恰是情感，而本作的师叔暗线在文档层面被降级成了「保留钩子」。系统骨架越完整，这游戏越像「合格的模拟经营+养成」——上线后最可能的评价是「还行，就是记不住」。这不是现在就要写剧情的理由，但 16 岁段内容规划前必须补上乐趣定位。（2026-09-10 进展：叙事渗透四接口已定，见 GDD v2 §6，暗雷已拆一部分。）

## 1. 核心乐趣假设（Fun Hypothesis）

> **在有限的回合里，我用洞天养女儿、女儿的际遇反哺洞天——看着「这个家」和「她」互相成就着变好，而且她的变化每一回合都看得见。**

两个引擎：**双线咬合的复利感**（经营杠杆）+ **成长可见**（养成情感）。拆成三个可验证子假设：

| # | 假设 | 内容 | 验证方式 | 失败信号 |
|---|---|---|---|---|
| H1 齿轮咬合 | 玩家能明确感知「两线在互相喂」：洞天产出帮女儿（灵草减压、礼物、活动载体）；女儿的活动与际遇（比赛图纸/称号、冒险 Boss 物品、配角剧情）反哺洞天。**三主体结构（2026-09-10 修正）：洞天由父亲解锁，女儿属性数值不做洞天门槛，女→洞只走事件载体** | 咬合感强度与「交换事件的可感知频率」正相关 | 交换事件×回合分布表（GDD v2 §7.2）；D1+D2 已含洞→女最小链（草减压），女→洞事件待后续原型验证 | 前段玩家把洞天晾成挂机农场（咬合太松/太慢）；或玩家抱怨两边必须齐头并进（咬合变枷锁——基线已明确「进度独立」，这是正确的防御，别破） |
| H2 压力节奏器 | 压力梯度（期望倍率 1.50→1.30→1.00→0.90）让「这回合继续堆培养还是回血」成为真实决策；减压靠洞天产品，压力因此是咬合的最小单位 | 观察试玩者是否在高压力回合自发改变排程/吃草 | 试玩观察：第 2-3 回合是否有人主动看压力条并调整 | 没人理压力条（梯度太平或反馈不外显）；或每回合被迫固定花精力减压（变成另一种税） |
| H3 成长可见（换载体） | 「她变了」的反馈必须持续供给，但载体从旧版的「破境大爽点」全换为：培养结算逐项判定（大成功动画）、立绘三阶段、功法六槽配装、比赛名次与称号、御灵入住 | 反馈通道审计：任意连续 3 回合至少命中一次「新变化」 | playtest 记录玩家主动打开女儿面板的频率 | 连续 2-3 回合无任何「她变了」时刻 → 反馈通道断粮，养成感塌方 |

### 旧版两条假设的去向

| 旧假设 | 处理 | 理由 |
|---|---|---|
| H1 养成感（成长被看见的频率） | 改造保留，收敛为新 H3 | 内核成立，但旧载体（境界突破/立绘换装按境界）在新基线已不存在 |
| H2 师叔暗线（真相揭晓的情感爆发） | **降级为长线叙事保留钩子**，不再作为核心乐趣引擎 | 新基线文档几乎全是系统规则，叙事内容尚未展开；它仍可能是本作差异化（对标《火山的女儿》的情感强度），但当前无法验证，不该占核心假设位。风险单独记录：**系统骨架成立≠这个游戏有人味**，叙事缺口需要在 16 岁段内容规划前补上乐趣定位 |

## 2. 设计支柱（5 条，冲突时按序优先）

| 序 | 支柱 | 一句话判据 | 冲突时的角色 |
|---|---|---|---|
| P1 | 成长可见 | 任意连续 3 回合，玩家至少看到一次「她/这个家变了」（结算动画、面板、立绘、称号、御灵入住） | 生命线。反馈断粮时砍任何东西先保它 |
| P2 | 齿轮咬合，但不锁死 | 两线频繁互相受益，但进度独立——生活类结局不查洞天进度，砍掉一边另一边也玩得下去 | 差异化核心。别用「强制同步进度」制造假咬合 |
| P3 | 排程永远有取舍 | 培养槽、自由活动精力、出发次数、压力现状构成稀缺；不存在全场景最优解 | 崩坏警戒：两个熟练玩家前 10 回合排程若 80% 重合，说明出现 dominant strategy，要重调 |
| P4 | 经营是杠杆不是第二份工 | 洞天深化服务养成与叙事，不引入独立刷取焦虑（御灵无经验、伙伴无等级） | 范围刹车。任何「为了经营好玩」的新系统先过这条 |
| P5 | 二周目是放大器不是重来 | 继承点预算带来数值爆发而非重考；一周目结算时玩家能说出至少一个「下局想试」的方向 | 保留钩子。验证放在一周目通关访谈，不提前建内容 |

优先级理由：P1 最高是因为养成品类反馈断粮即死，P2 是本作区别于一切单线养成的存在理由；P2 依赖 P1 先成立（咬合交换本身就是一种「可见成长」），故排第二。

## 3. 核心循环三层拆解

### 3.1 即时层（0-30 秒：动作→反馈→奖励）

| 侧 | 循环 | 决策密度 |
|---|---|---|
| 养成 | 拖活动入培养槽 → 预计收益即时预览 → 确认 → 逐项压力判定动画（大成功/成功/失败）→ 属性条跳动 + 女儿反应 | 决策集中在排程阶段；结算段是「看结果」。可接受，但判定动画必须短、可加速，否则 60 回合 × 多项会磨死耐心 `[PLACEHOLDER：单回合总操作+结算目标 ≤ 5 分钟，用 D1 实测]` |
| 洞天 | 点空地放建筑 → 道路连通即时校验 → 产出预测刷新 → 派御灵 → 预测再跳 | 放置/派工有决策；预测即时反馈已实现，是洞天侧即时层最强的钩子 |

已知结构问题（基线已自认）：自由活动先于培养 → 本回合培养的属性最早帮下一回合比赛。不是 bug，但若试玩者普遍建立不起「先排培养再比赛」的心智模型，需要用 UI 提示补（不改顺序）。

### 3.2 单局层（1 回合 ≈ 5-30 分钟）

回合开始主线/支线判断 → 自由活动与冒险（花精力）→ 洞天管理 → 确认日程 → 培养结算 → 生产入库 → 剧情升级判断 → 回合末减压 → 下一回合。

三个张力来源：

1. **精力稀缺**：比赛、冒险、社交、减压全挤自由活动精力，回合内必须取舍。
2. **压力现状 vs 培养野心**：高压力回合敢不敢继续堆（H2 的主场）。
3. **跨回合供应链**：第 N 回合的草最早第 N+1 回合加工、N+1 回合末入库——这个结算延迟是洞天侧最像「经营决策」的部分（种什么/炼什么/给谁留料），也是缺料分配规则（基线待定项）必须尽快定案的原因：它直接决定这层决策是否存在。

失败信号：玩家形成固定回合模板——每回合同排程、同派工、无脑确认 → 单局层决策密度塌了，优先查精力预算与压力梯度，而不是加内容。

### 3.3 长期层（60 回合 / 12-24-24 三阶段）

| 阶段 | 往合数 | 循环职责 | 咬合职责 |
|---|---|---|---|
| 4 岁（1-12） | 12 | 建立基础排程与压力管理习惯 | 前 12 回合内至少完成一次完整往返：女儿解锁→洞天受益，且洞天产出→女儿受益（清心草减压链已实现一半） |
| 10 岁（13-36） | 24 | 循环升维：冒险开放（剧情物品→父亲恢复/土地）、四艺比赛（称号→杂学→产品强化）、境界主线触发（A≥阈值） | 交换事件的主要投放段，H1 的成败在这里 |
| 16 岁（37-60） | 24 | 收束与分岔：结局判定（人生/结缘分别结算）、真结局 Boss（复制 A 的镜像战）、继承点结算 | 交换事件应退场，让位给结局分岔与镜像战 |

保留钩子：结局分岔 + 继承点预算 + 一周目刻意未解锁的方向（御灵/图纸/结局/道途）。单局总时长 `[PLACEHOLDER：60 回合 × 单回合 5 分钟 ≈ 5 小时下限；目标区间 6-10 小时，用原型实测回填]`。

---

## 4. 最脆的假设与验证路径（按现有 D1+D2 原型）

**最脆的是 H1。** 三个具体缺口：

1. **交换事件没有回合分布表**。御灵解锁、图纸、关键配方、剧情物品各在第几回合可得，目前无表。如果交换事件集中在中后期，前 12 回合就是两个单机并行，H1 直接落空。行动：出一张「交换事件 × 回合」分布表，前段密度不足就前移，这张表同时服务 H1 验证和内容排期。
2. **洞天受益目前不依赖女儿**。原型里御灵、地块、七种建筑直接开放，缺「女儿养成 → 解锁御灵/图纸」这半边齿轮。行动：补一条最简解锁链（例：音律培养到 X → 解锁第二只御灵），即可在原型里测完整往返。
3. **压力链是最小可测单元**。清心草（洞天）→ 减压（女儿）→ 判定期望（1.5x vs 0.9x）已经实现，这是 H2 的现成实验台。行动：找 2-3 人试玩前 6 回合，只观察一件事——他们是否因压力改变了排程。
