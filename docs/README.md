## 状态与维护

- **已确认**：用户明确接受的规则。确认后同步到 01，并更新相关草案。
- **试算基线**：已接受用于试作的暂定值，不代表最终平衡。
- **提案 / 待定**：不能直接当成开发承诺；具体问题集中到 04。
- **已实现**：以 05 和代码为准，不能根据设计文档推断功能已存在。
- **后置**：不影响当前主体闭环，暂不扩充实现范围。

草案中明确废弃的内容不留在正文反复对照；已确认的新方向同步清理对应残留。其余未确认的冲突记入 04，不由整理者自行决定。修改当前规则时先确认，再把被替代的内容归档。

## 工程范围

女儿培养与父亲洞天经营相互支持、进度独立。小游戏属于增强体验，优先完成主体、交互和最小内容链。工程使用 Godot 常规目录，不增加不必要的架构、兼容层或专用编辑器。

当前分工：助手搭通用框架与少量示例，用户自行填写具体内容；不再逐项确认药材、丹方和数值，仅对影响结构或存在冲突的规则提问。示例不是正式内容定案，也不表示未实现系统可以直接填表启用。
