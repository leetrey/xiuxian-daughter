## 状态约定

- **已确认**：对话中已明确接受的规则；集中记录在 01。
- **试算基线**：可用于估算或原型的暂定数值，不等于经过试玩验证的最终平衡。
- **提案**：为落地提出的界面、字段、文件名或技术边界，尚未视为定案。
- **待定**：缺少选择或信息，必须明确保留，不能由旧文档悄悄补齐。
- **后置**：不影响主体闭环，暂不扩充实现和测试范围。

规则引用以 01 为准；02、03 不能默默改变规则，未确认的选择集中进入 04。后续修改已确认规则时，应先获得用户确认，再同步受影响的文档。

## 范围原则

主体是女儿培养与洞天经营两条相互支持、进度独立的路线。剧情、冒险、战斗、伙伴和继承服务于主体闭环。

四艺比赛的资源、图纸、称号奖励仍属于养成链条；复杂小游戏只是锦上添花。先设计清楚主体与交互，不为非核心玩法主动追加模式、分支、通用框架和大量测试组合。

工程只保留 Godot 常规目录组织。旧工程由 vibe coding 生成，不要求保留其脚本结构或为旧代码、旧存档增加兼容工程。
